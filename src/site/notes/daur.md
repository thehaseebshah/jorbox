# Daur

## How to Play
**Inspired by:** + Gattu Daur + Jazeeray + Pass an Object

- **Age Limit:** 14+
- **Group Size:** 5–10 players
- **Duration:** 30 minutes
- **Prep Time:** < 5 minutes
- **Difficulty:** 5
- **Code:** O-011
